# Python Calculator

A command-line calculator that supports basic arithmetic operations and allows users to continue calculations using the previous result.

## 🧮 Features

The calculator supports four basic mathematical operations:

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`

The calculator also allows users to:

* Continue calculating with the previous result
* Start a new calculation
* Perform multiple calculations in one session
* Enter decimal numbers
* Handle invalid numeric input
* Handle invalid operation choices
* Prevent division by zero
