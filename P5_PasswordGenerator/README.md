PyPassword Generator

A Python project that generates randomized passwords.

Project Overview

The program asks the user how many letters, symbols, and numbers they
want and then creates a password containing the requested number of each
character type. The characters are shuffled so that the password does
not follow a predictable pattern.

Requirements

Python 3.x

No external libraries are required.

The project uses Python's built-in random module.

How to Run

Make sure Python 3 is installed.

Clone or download this repository.

Open a terminal in the project directory.

Run:

python main.py

Enter the desired number of letters, symbols, and numbers.
