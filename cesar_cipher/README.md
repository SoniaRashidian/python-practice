# Caesar Cipher

It is a classical substitution cipher that encrypts and decrypts messages by shifting letters through the alphabet.

## 🔐 How the Caesar Cipher Works

The Caesar Cipher shifts each letter in a message by a fixed number of positions in the alphabet.

For example, with a shift of `3`:

```text
a → d
b → e
c → f
...
x → a
y → b
z → c
```
